## 2. 缺口逐条

### GAP-01 邻段漂移的归因需三跑设计

- **现状**:b5.3 在 Courier-en 上匹配 123 段、15 段变(4 链成员 + 11 邻段),同时测得
  `gpt-4o` 在 `temperature=0` 下同一 prompt 三答、相似度 0.989 / 0.995(台账 A-12、G-01)。
  11 处邻段变化的量级与词级重采样噪声同量级;而 prompt 未变的段落是**从缓存取回的,
  因此按构造相同而非按测量相同**,该设计无法分辨两者。
- **补法**:上表 R1。`chain_off` 两跑绕缓存给出引擎重复噪声的分布,`chain_on` 一跑给出
  重组后的取值;重组效应 = 后者与前者分布的差。
- **成本**:约 90 次调用 / 5~6 万 prompt tokens / 13 分钟(依据见 1b)。
- **不补的措辞**:
  > 链级联合翻译在被重组的页上同时改变了链成员与其同批邻段的译文。邻段变化(11 处,
  > 页 2/7/8)在词级选择上与本引擎在 `temperature=0` 下的重复采样噪声(实测相似度
  > 0.989–0.995)同量级,本文的单跑设计无法分辨二者,故**只报告其存在与规模,不对其
  > 成因作断言**。

### GAP-02 LOPO 逐折矩阵没有产物

- **补法**:1a 中的 B-02 行——在 v2 语料上按刊物留一重做 LOPO,产出新的逐折矩阵并入库。
- **成本**:零 API,确定性,E1 内完成。
- **不补的措辞**(且 0.938 一律**不得出现在论文中**):
  > 泛化性以按刊物留一交叉验证的方式配置,所有自适应组件在配置时不接触留出刊物
  > (背景章 §2.7)。本文报告的是全语料一致率 0.879 (29/33)(v2 语料);逐折数字在语料
  > 换血中未予保留,故不作留出集主张。

### GAP-03 GEMBA-MQM 判官的同源偏倚

- **现状**:被测系统用 `gpt-4o`。若判官也用 `gpt-4o`,判官与被测同源,系统性偏向自身输出
  的风险无法排除;kocmi2023 自己给出的告诫正是对专有黑盒的依赖(背景章 §2.7)。
- **补法二选一(用户决策)**:
  - **(a) 异源判官**:判官改用非 `gpt-4o` 族模型;偏倚论证成立,代价是判官本身的质量需另行说明。
  - **(b) 同源 + 声明 + 人工抽验**:沿用 `gpt-4o` 判官,在论文中显式声明同源偏倚,
    并对 ≥20% 的拼接点做人工复核,报告判官与人工的一致率。
- **成本**:(a) 与 (b) 的 API 成本相同(≤70 次);(b) 额外约 7 个拼接点的人工工作量。
- **不补的措辞**(即两条都不做时):
  > 拼接点标注由一个与被测系统同族的大模型给出,判官与被测系统同源,其结果**只作定性
  > 错误类型的提示,不作为质量排序的依据**;全部判官回复已缓存并可逐字节重放。

### GAP-04 `escalation_surfacing` 零活证据

- **现状**:b8.3 与 b8.4 合计 **12 次真跑**,`escalation_surfacing` 一次未触发(台账 E-09)。
  该检测器至今只被 b8.1 的 fixture 与门禁的合成场景运行过。同类情况还有
  `converged_with_residuals`(b8.4 §6,同样只有合成场景)。
- **补法**:上表 R3——构造一条超过 `max_tokens=2048` 的链,让它走 `translation_unavailable`
  逃生路径,从而生成真实的 escalation 记录。
- **成本**:1 份合成文档、数次调用;实现代价小于运行代价。
- **不补的措辞**(推荐直接采用,合成覆盖声明):
  > `escalation_surfacing` 与 `converged_with_residuals` 两条路径由合成场景覆盖并在门禁中
  > 逐次断言,**在真实语料的十二次运行中均未被触发**。本文因此把它们记为"机制已实现且
  > 有合成覆盖",而不记为"已被文档验证"。

### GAP-05 "v1 修复零落地"的三段式措辞 —— 已被 batch-b8.4 推翻,须重述

> **与 PLAN_E0 前提不符,现场记录。** PLAN_E0 D3 把"v1 修复零落地的三段式措辞"列为
> "已定,登记为合同"。该前提在 batch-b8.3 时成立(6/6 conserved、0 段修复,台账 E-03),
> 但 **batch-b8.4 有三处修复进入成品 PDF 且盒不变**(台账 E-06,本会话已从
> `examples/output/b8_4/smoke/evidence.json` 现场复核 `box_held: true` ×3)。E0 是盘点批次,
> 因此按事实登记而非转录旧措辞。

- **重述后的三段式**(建议作为新合同):
  1. **机制成立**:检测 → 决策 → 带裁决送出 → 写回 → 增量重排 → 复检的完整链路在真实
     语料上跑通,**三处修复进入成品 PDF**(CERNCourier-en `p2#32`、FD-en-v2 `p5#14` 与 `p5#9`),
     每一处的段落盒保持不变。
  2. **主角缺陷被拒,且拒因是结构性的**:B8 线全程的主角 `p6#15` 在被正确读序、正确翻译、

     竖条更大的面积(746 pt² → 69 700 pt²)。这是能力边界而非实现缺陷,守卫拦下了一次
     会毁版的"成功"。
  3. **一处结构性不可达**:`p1#9` 是译者已渲染过的乱序标题,v1 动作词表中无一条能回答它,
     且为其写的裁决条目匹配不到任何 prompt。
- **成本**:零(纯措辞)。
- **不补的后果**:论文会写出一个被自己产物推翻的说法。**必须补。**
