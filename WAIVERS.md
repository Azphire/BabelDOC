| W-B7-02 | `magazine/drop_cap.py`, `magazine_drop_cap_mark` | Every magazine switch so far is a `TranslationConfig.__init__` parameter, which is an upstream edit. | W-B7-01 | `magazine/hitl.py`, `apply_terms` | PLAN_B7's T7.1 injection assumes a ruling placed in `user_glossaries` reaches the translator. The corpus owner chose the injection-side rebuild over an upstream change to that rule, so the injection additionally moves the rebuilt automatic glossary into the user glossary list and empties the automatic slot: both tables then reach the translator under either setting, and no upstream behaviour is edited. Consequence: with `magazine_hitl_apply` and `save_auto_extracted_glossary` both on, `pdf_creater.py` and `result_merger.py` read an empty slot and write no `auto_extracted_glossary` CSV beside the output. The same content, plus what the ruling dropped from it, is recorded in `hitl_apply.report.json`. | The selection rule returns user glossaries alongside the automatic one, after which the ruling can stay in the user list and the automatic slot is left as it was. | B7 |
