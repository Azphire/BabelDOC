## 2. T1 —— 恒等写回不得触发重排

### 2.1 死代码判定

`post_translate_paragraph(paragraph, tracker, translate_input, translated_text)`
的第三参数是 `ILTranslator.TranslateInput`。该类无 `__eq__`,故
`translated_text == translate_input` 是 `str.__eq__(str, object)` → `NotImplemented`
→ 回退恒等性比较 → **恒为 False**。四个调用点无一传字符串。短路自存在起从未执行过。

### 2.2 改法(上游一处)

`il_translator.py`:新增模块级 `_normalised_for_identity` 与
`_is_identity_write_back`,比较改为对 `translate_input.unicode` 取值,判据为
**NFKC 归一化 + 去首尾空白后逐字节相等**;规范化只用于判定,不改写任何文本。
非 `TranslateInput` 的入参退回原比较,不抛异常。分支体一字未动。

最小 diff:

```
-        if translated_text == translate_input:
+        if _is_identity_write_back(translated_text, translate_input):
```

`short_unit.py` 增一个记录字段 `identity_skipped`,取 `post_translate_paragraph`
的返回值(恒等时返回 `False`)。

## 9. 遗留问题

1. **W-B11-01 的代价没有兑现**。T1 与 T2 都是上游行为变更,影响面是全语料,本批
   只在 FD 上验证。其余五样张的回归要到下一次全量跑才暴露。**T1 的面尤其大**:
   凡"模型原样返回源文"的段落,行为从"按映射字体重排"变成"原样保留",这在
   Courier-zh 这类反向样张上会碰到更多段落。
2. **`p5#0` `Masthead` 未译**(§2.3)。属 T3 换 prompt 后的重采差异,不是 T1 缺陷,
   但页面上确实是一处回退。gpt-4o 在 temp=0 下非确定,单跑无法区分"档的系统性
   影响"与"一次采样"。
3. **T2 的回退会改变段落的缩放**(§3.4)。p3#25 由 scale 0.95 落到 0.90,字号
   22.8 → 21.6。这是缩放搜索的既有机制,不是新行为,但**悬挂界会更频繁地触发它**。
   本批 7 处 `pulled_back`,其中多少处引发了降档未逐段核对。
4. **b10.4 的三条断言此后不再实际执行**(AC-11)。其完整译后 PDF 与 working dir
   已被保留策略淘汰且不得重跑顶替。
5. `typeset_hang.report.json` 只记**越出盒外**的悬挂。盒内的悬挂(绝大多数)不记,
   否则 sidecar 会膨胀到无法读。这是刻意的语义,写在此处以免日后被读成"漏记"。
