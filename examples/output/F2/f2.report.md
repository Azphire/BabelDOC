# F2 — full-stack review run

Six samples, one run each, every magazine switch up and both rulings under
`reviews/` applied. This is not an evaluation: nothing is ablated, nothing is
compared against a baseline, and no mechanism was changed to produce it. The
artefact is the finished PDF; this file is the index to read it with.

Its one purpose is to help find what still needs correcting. Section a says
which mechanism fired where, so a claim can be checked by turning to a page.
Section b is the terminal state of the eight defects the F1 review recorded.
Section c is the open items, each with the page it can be seen on. Section d is
what reading all forty-one pages found that no list above carries.

Configuration and per-sample digests in `f2.manifest.json` beside this file;
the per-mechanism data the tables below are built from is in
`f2.mechanisms.json`, which stays in the workspace with the rest of the run's
products and is rebuilt by `scripts/analyze_f2.py`. Page numbers are the PDF's
own, one based.

**#3 — display titles.** Two of the three F1 cases are closed and the third is

- *Courier-en, headings wrapping and breaking inside words* — **closed**. Six

  clipped: the reader sees **希贾兹铁** and a half glyph.
  Batch b9.2 halved four runs to two; the remaining two are the same defect at
  half size.
